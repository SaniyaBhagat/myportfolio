1. AlgoMaster – Algorithm Visualizer & Learning Platform

Tech Stack: HTML, CSS, JavaScript, PHP, MySQL

An interactive educational platform designed to help users learn and visualize algorithms like sorting and searching. It features step-by-step animated execution, user login and tracking, "Add to Visualizer" and "Add to Choice" features, and a feedback/report generation system. AlgoMaster aims to make algorithm learning engaging and easy through hands-on practice and real-time progress tracking.
GitHub Link: github.com/SaniyaBhagat/AlgoMaster

2. Crop Yield Prediction

Tech Stack: HTML, CSS, JavaScript, Python (Flask), Machine Learning (Scikit-learn), MySQL

A web-based application that allows users to input parameters like soil type, temperature, rainfall, and crop name through a clean user interface. The backend sends this data to a trained machine learning model, which predicts the expected crop yield. Results are visually displayed for easy interpretation and decision-making, especially useful for farmers and agricultural planners.

3. Promovies – Online Movie Ticket Booking Website

Tech Stack: HTML, CSS, JavaScript, PHP, MySQL

A dynamic web platform that enables users to browse movies, select showtimes, book seats, and make online payments. The system supports real-time seat availability, secure login, and a user-friendly interface for managing bookings. It integrates backend processing with a structured database and includes admin-level access for movie/showtime management.
